# ttrpg-gm-campaign-manager
Campaign Manager for TTRPG Gamemasters to display maps, manage sessions, and display and hide content from players.

See [Development commands](docs/development.md) for how to run, build, and clean the app.

The first headless Rust/Turso foundation is available. See [Headless development](docs/headless-development.md) for CLI examples, protocol behavior, checks, and the capability ledger.

See [Headless core, CLI, and Rune](docs/headless-core-plan.md) for the proposed architecture direction, migration phases, and open discussion questions.
